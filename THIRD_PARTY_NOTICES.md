# Third-party notices

lib-image contains no third-party code. Formats follow their public
specifications: RFC 1950 (zlib), RFC 1951 (DEFLATE) and the PNG
specification (ISO/IEC 15948, W3C PNG Third Edition). The format tables
(DEFLATE's length and distance bases and code length order) are
interoperability constants from those specifications.

The Paeth predictor's threshold form in `crates/png/src/filter.rs` is an
algebraic identity of the PNG specification's predictor, checked against
it for every input by the tests.

## Test fixtures

- `crates/png/tests/fixtures` are generated by the scripts in `tools/` with
  Python's zlib and Pillow.
